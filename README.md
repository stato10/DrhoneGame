# DrhoneGame — סוכן צללים

## חדש: חילוץ רחפן (0.3)
באתר https://stato10.github.io/DrhoneGame/ בחרו ״משימת רחפן״, או פתחו drone.html.

12 שערים עם מהירות עולה, שלוש יחידות מגן, נעילת מידע וניקוד. במצב חיישנים נדרשות דגימות עדכניות משני המקורות לפני תחילת הטיסה. ״כיול והתחלה״ מאפס את תנוחת הראש והיד הנוכחית; הטיית יד מכוונת את הרחפן, סיבוב ראש מכוון את הסורק, ואישור נועל מידע כשהכוונת קרובה למטרה. ניתוק דגימות או מעבר לרקע משהים ומשחררים חיישנים. חידוש דורש חיבור וכיול מחדש ושומר את מצב המשימה.

אימון מקלדת נפרד: חצים להיגוי, A/D לכיוון הסורק, Enter לנעילה ו־Escape להשהיה. השיאים נשמרים בנפרד לכל מצב. אין הקלטה או שליחת נתוני חיישנים. תגובת ציוד הכיול אושרה על ידי המשתמש; שליטת הטיסה עצמה עדיין דורשת בדיקה על המשקפיים.

משחק ריגול ניסיוני ל־Meta Ray-Ban Display, עם גרסת דפדפן ובדיקת ציוד. זהו מאגר עצמאי: אין תלות במאגרים אחרים, שרת חיצוני, חשבון, מפתחות API או שירות AI.

## מה כלול
- משחק בן שתי דקות: איתור אות, מנעול שלוש טבעות ומשימת יציבות.
- צלילים מקומיים, ניקוד, שיא אישי בדפדפן והשהיה במעבר לרקע.
- מסך כיול נפרד: נתוני כיוון ראש, תנועת צמיד ניסיונית, ניווט ואישור.
- מצב הדגמה המסומן במפורש, ויצוא דוח בדיקה ללא נתוני תנועה גולמיים.

## הפעלה במחשב
אפשר לפתוח `index.html` ישירות כדי לשחק. לבדיקת חיישנים הפעילו שרת מקומי באמצעות Node.js 22 ומעלה:

```sh
npm start
```

פתחו http://127.0.0.1:8080/ למשחק או http://127.0.0.1:8080/calibration.html לכיול. אין צורך ב־npm install. עצירה: Ctrl+C.

חלופה עם Python:
```sh
python -m http.server 8080 --bind 127.0.0.1
```

## שליטה
- חצים: כיוון הסורק או סיבוב הטבעת.
- Enter: אישור טבעת. אפשר גם להשתמש בכפתורי המסך במחשב.
- P או Escape: השהיה והמשך.
- במשימת היציבות, ללא חיישן פעיל המשחק מסומן כתרגול מקלדת.

## בדיקה במשקפיים
הכתובת המקומית של המחשב אינה נגישה למשקפיים. כדי לבדוק במכשיר יש לארח את קובצי הווב בכתובת HTTPS נגישה ולהוסיף אותה דרך Meta AI במצב מפתחים. המאגר אינו מגדיר פריסה אוטומטית או GitHub Pages.

במסך ״כיול ציוד״:
1. הפעילו חיישנים והמתינו לדגימות.
2. הזיזו ראש ופרק יד בנפרד ובדקו שהמד המתאים מגיב.
3. כיילו תנוחת אפס נוחה ובדקו חצים ואישור.
4. הורידו דוח לצורך בדיקת התאימות. אין העלאה אוטומטית של הדוח.

## מצב הפיתוח — מגבלות ידועות
**זו גרסת אב־טיפוס, לא גרסה שתאימותה לחומרה אומתה.**

- תנועת ראש: `DeviceOrientationEvent`, בכפוף להרשאות וזמינות.
- צמיד: ניסיון שימוש ב־`RelativeOrientationSensor` עם `sensorId: emg-wrist`, על בסיס דיווחי קהילה. הממשק המדויק ומקור הדגימות עדיין אינם מאומתים בחומרה. דפדפן עלול להתעלם ממזהה החיישן ולהחזיר נתונים ממקור אחר.
- קבלת אירועי חצים או אישור אינה מוכיחה שהמקור הוא צמיד פיזי.
- מסך הכיול משחרר חיישנים במעבר לרקע; צריך להפעיל מחדש כדי להמשיך.
- ערכי הכיול עדיין אינם מוזנים למשחק או נשמרים בין הדפים.
- משימת הרחפן ממומשת בנפרד ב־drone.html; אין עדיין מצלמה, מיקרופון או זיהוי עצמים.
- אין כרגע גישה למצלמה, מיקרופון, זיהוי עצמים או אפליקציית iOS.
- בדיקות הלוגיקה אינן מחליפות בדיקות תצוגה, ביצועים וקלט ב־Ray-Ban Display.
